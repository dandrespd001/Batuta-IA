# Snapshot de auditoría histórica K0.5, K1.2, K2.3 y K3.3

Este snapshot conserva la reconstrucción contractual disponible el 28 de agosto
de 2026. No afirma que exista evidencia roja tomada antes de implementar.

- K0.5: el validador de evidencia exige JSONL cerrado y rojo/verde/mutación.
- K1.2: calidad separada por ruta exacta y acción, compatibilidad estricta,
  revisiones no mezclables y overrides append-only.
- K2.3: `StateManifestV2` publica cinco objetos inmutables por contenido y una
  generación; alterar un objeto se detecta antes de ensamblar.
- K3.3: `RouteRequestV2` no acepta reloj, clase, fallback, candidatos, perfiles
  ni hashes; el servicio deriva contexto confiable y cruza permisos solicitados
  con política.

Los comandos conservados en los registros son verificaciones reconstruidas del
estado final. Los tests y mutaciones siguen siendo útiles para regresión, pero no
se etiquetan como TDD retroactivo.
